# Personal Portfolio

A responsive single-page developer portfolio built with **HTML, Vanilla CSS, and JavaScript**.

## Overview

This portfolio showcases my projects, technical skills, experience, certifications, achievements, and contact information through a clean, responsive single-page interface.

## Features

- Responsive single-page design
- Smooth section navigation
- Interactive UI elements
- Project showcase
- Skills and technology overview
- Experience and achievements
- Certifications
- Contact section
- Back-to-top navigation

## Tech Stack

- HTML5
- Vanilla CSS
- JavaScript
